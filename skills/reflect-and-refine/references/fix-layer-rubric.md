# Choose the smallest effective fix

1. Can a data structure, architecture or enforced contract eliminate the failure?
2. Can focused validation catch it before delivery?
3. Can the existing workflow owner fix the repeatable gap with a small change?
4. Is it a task-specific ambiguity that belongs in the prompt or a clarifying decision?
5. Create a new skill only when a distinct recurring workflow has no owner.

Name the observed cause, evidence, exact change target, expected benefit and a check that would catch the original failure. Rank competing fixes by consequence, recurrence and effort; state uncertainty. Normal exploration, new requirements and unavoidable source delays do not automatically justify a durable change.
