# General work Skills

Three starter Skills to keep bigger projects moving, review work together, and improve the process. These are general adaptations. Copy the installation prompt for the Skill you want into your agent.

## Manage Work

Keep a substantial task moving with a clear backlog, useful milestones, and checked results. [View the files](https://github.com/kobex-oai/starter-skills/tree/main/skills/manage-work).

```text
Install Manage Work from https://github.com/kobex-oai/starter-skills/tree/main/skills/manage-work

Inspect the folder and preserve all supporting files. If I already have it, show me the diff before replacing it. Verify the actual installed location and how to use it. If installation isn’t supported here, give me exact manual steps for this tool.
```

Keep each Skill folder intact. Reflect and Refine also needs `references/fix-layer-rubric.md`. These are instruction-only Skills with no external packages or background process. [See the file manifest](skills-manifest.json).
